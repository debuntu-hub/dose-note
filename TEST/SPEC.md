# Dose Note - アプリ仕様書 (SPEC.md)

本仕様書は、頭痛薬服用記録アプリ「Dose Note」の唯一の正（Single Source of Truth）です。
開発は本仕様書に基づき行い、変更がある場合は必ず本ドキュメントを更新してから実装を行います。

---

## 1. アプリ概要

### 1.1. 目的
ユーザーが頭痛薬を服用したタイミングで簡単に記録し、その頻度や間隔を可視化することで、自身の体調管理や服薬ペースの把握を支援する。

### 1.2. ターゲットユーザー
- 頭痛持ちで、薬を飲む頻度を気にしている人
- 服用間隔を管理したい人（飲み過ぎ防止、傾向把握）

### 1.3. 対応プラットフォーム
- **OS**: iOS 17以降
- **デバイス**: iPhone

## 2. 機能一覧 (Features)

| ID   | 機能名           | 内容                                                                 | Free | Premium |
| :--- | :--------------- | :------------------------------------------------------------------- | :--: | :-----: |
| F-01 | 服用記録         | トップ画面のボタンタップで現在日時を記録                             | ○    | ○       |
| F-02 | 今月の統計       | 当月の服用回数を表示                                                 | ○    | ○       |
| F-03 | 今月の平均間隔   | 当月の平均服用間隔（日数）を表示 ※注1                                | ×    | ○       |
| F-04 | 全期間の統計     | 全期間の総服用回数と平均ペースを表示                                 | △(※) | ○       |
| F-05 | 履歴カレンダー   | カレンダー形式で服用日を確認（ドット表示）                           | △(※) | ○       |
| F-06 | 履歴詳細リスト   | カレンダーで選択した日付の服用詳細を表示                             | ○    | ○       |
| F-07 | 履歴編集・削除   | 記録済みデータの日時変更、削除                                       | ○    | ○       |
| F-08 | 統計グラフ       | 服用間隔の推移を折れ線グラフで表示                                   | ×    | ○       |
| F-09 | 課金画面(Paywall)| 機能比較、サブスクリプション購入、復元                               | ○    | ○       |

* (※) Freeプランの制限事項
    *   **全期間の統計**: ロック状態で詳細数値は非表示（「詳しく見る」ボタン表示）
    *   **履歴カレンダー**: 直近30日以内のデータのみ表示

* 注1: 平均間隔の計算ロジック
    *   `(現在日時 - 最初の服用日時) / 服用回数` で算出
    *   服用していない期間が長引くと、自動的に平均間隔（日数）が増加する仕様

## 3. 画面仕様 (UI/UX)

### 3.1. ホーム画面 (ContentView)
*   **ヘッダー**: アプリ名 "Dose Note"
*   **今月の記録カード**:
    *   服用回数（大きく表示）
    *   平均間隔（Premiumのみ数値表示、Freeはロックアイコン）
*   **全期間の記録カード**:
    *   Premium: 総回数、全期間平均、グラフ画面へのリンクボタン
    *   Free: ロック表示、「詳しく見るには」ボタン（Paywallへ遷移）
*   **アクションボタン**:
    *   「頭痛薬を飲んだ」ボタン（青色、画面下部）
    *   タップ時に即座にデータ保存
*   **ナビゲーション**:
    *   履歴画面へのリンクボタン

### 3.2. 履歴画面 (HistoryView)
*   **表示形式**: カレンダービューのみ
    *   Freeプランの場合、「過去30日分を表示中」のアラートとPremium誘導を表示
*   **操作**:
    *   日付タップ: その日の記録リストを下部に表示
    *   リスト項目タップ: 編集画面へ遷移
    *   リスト項目スワイプ: 削除

### 3.3. 編集画面 (EditDoseView)
*   **要素**: DatePicker（日本語ロケール）
*   **アクション**: 保存ボタンで更新

### 3.4. 統計分析画面 (StatsView)
*   **対象**: Premiumユーザーのみ
*   **グラフ**: 服用間隔（前回からの経過日数）の推移折れ線グラフ
*   **インサイト**: 直近の間隔、全期間の平均ペースをテキスト表示

### 3.5. 課金画面 (PaywallView)
*   **要素**:
    *   Free vs Premium 機能比較表
    *   プラン選択ボタン（月額 / 年額）
    *   購入の復元ボタン
    *   サブスクリプション管理（解約）へのリンク
    *   免責事項（医療行為ではない旨の明記）
    *   利用規約・プライバシーポリシーへのリンク
*   **デバッグ**: Debugビルド時のみ「無料でアンロック」ボタンを表示

## 4. データ設計

### 4.1. モデル (Dose)
```swift
struct Dose: Identifiable, Codable {
    let id: UUID
    var date: Date
}
```

### 4.2. 永続化
*   **保存先**: `UserDefaults`
*   **キー**: `"doses_history"`
*   **形式**: JSONエンコードされた `[Dose]` 配列

### 4.3. 状態管理 (Store)
*   `DoseStore`: データのCRUD操作、統計ロジックを担当
*   `StoreManager`: StoreKit 2を用いた課金状態の管理

## 5. 課金仕様 (In-App Purchase)

| ID | タイプ | ID文字列 (例) |
| :--- | :--- | :--- |
| 月額プラン | Auto-Renewable | `premium_monthly` |
| 年額プラン | Auto-Renewable | `premium_yearly` |

*   **制限ロジック**:
    *   アプリ側で `StoreManager.isPremium` フラグにより判定
    *   データ自体は削除せず、表示フィルターやナビゲーション制限で制御する（"データは保持、機能だけ制限"）

## 6. その他・ルール

### 6.1. 免責事項
アプリ内（Paywall等）に以下の主旨の免責を必ず記載する。
> 本アプリは服用履歴を記録・管理するためのツールです。医療行為、診断、治療を目的としたものではありません。

### 6.2. 開発ルール
1.  **仕様最優先**: コード変更前に `SPEC.md` を更新する。
2.  **安全性**: リリースビルドにデバッグ機能を含めない（`#if DEBUG` 使用）。
3.  **ローカライズ**: 多言語対応（日本語・英語）を行う。システムの言語設定に従い、デフォルトは英語とする。日付フォーマット等もロケールに従う。
