# 📝 Product Requirement Document (PRD)

**プロジェクト**: TapKey
**作成日**: 2026年2月6日
**バージョン**: v0.1
**ステータス**: 🟢 PRD_DONE

---

## 1. プロダクト定義

### 1.1 コンセプト
**アプリ名**: TapKey
**サブタイトル**: One‑tap password creation & save

### 1.2 目的
* 各種サービスの認証情報を安全に保管し、**入力の手間を極力なくすこと**を主目的とする
* 特に「新しく作成したパスワードをアプリに保存する際の手入力」を最小化する
* パスワード管理アプリを「開く・考える・入力する」という行為自体を減らす

### 1.3 ターゲットユーザー
* 個人（自分自身）
* 既存のパスワード管理ツールが面倒だと感じている人

---

## 2. スコープ（MVP v0.1）

### 2.1 実装する機能（Must）
**最重要UX要件："極力入力しない"**

* **パスワード生成・保存**
  * 起動と同時に安全なパスワードを生成
  * 生成結果をそのまま編集なしで保存可能
  * サービス名・IDの入力補助（自動補完・クリップボード利用）
* **データ管理**
  * 追加 / 編集 / 削除
  * 一覧表示（検索機能付き）
  * メモ機能
* **セキュリティ・操作**
  * 生体認証ロック（Face ID / Touch ID）
  * ワンタップでのID/PWコピー
  * クリップボードの自動クリア
  * 完全オフライン動作（ローカル保存）

### 2.2 やらないこと（Out of Scope v0.1）
* iOS Password AutoFill 連携
* TOTP（2段階認証）
* パスワード強度評価・使い回し検出
* インポート / エクスポート
* 独自クラウド同期・Web版
* チーム共有機能

---

## 3. 成功の定義（KPI）

### 3.1 経営指標
* 自分が毎日ストレスなく使えること（ドッグフーディング満足度）

### 3.2 収益化モデル（v1.0以降）
**フリーミアム + 買い切り課金**
* **無料**: 基本機能（保存件数制限あり想定）
* **有料**: 無制限保存、AutoFill、TOTP等（¥980想定）
* **方針**: 広告なし、サブスクなし、ローカル完結

---

## 4. 前提条件・制約

* **プラットフォーム**: iOS（iPhoneのみ）
* **技術スタック**: SwiftUI, Core Data, CryptoKit, LocalAuthentication
* **安全性**: マスターPWなし、生体認証 + Keychain運用
