プライバシーポリシー

制定日: 2026年2月8日

本プライバシーポリシーは、TapKey（以下、「本アプリ」といいます）における利用者情報の取り扱いについて定めたものです。

1. 収集する情報

本アプリは、利用者のプライバシーを最大限尊重するため、個人情報を収集・送信しません。

  • 保存データ: パスワード・ユーザー名・メモなどの機密データは、AES-256-GCM方式で暗号化のうえ、すべて利用者のデバイス内（ローカルストレージ）にのみ保存されます。
  • 暗号化キー: 暗号化に使用するキーは、iOSのKeychain（Secure Enclave連携）に保存され、アプリ外への送信は一切行いません。
  • 解析データ: 開発者を含む第三者のサーバーへ、利用者のデータを自動的に送信することはありません。
  • ネットワーク通信: 本アプリはインターネット通信を行いません。すべての処理はデバイス上で完結します。

2. データの利用目的

本アプリに入力されたデータは、以下の目的でのみ利用されます。

  • アプリ内でのパスワード保管・表示・検索のため
  • 生体認証（Face ID / Touch ID）によるアクセス制御のため
  • iOSのシステム機能（StoreKit）による定期購読（サブスクリプション）の管理のため

3. 生体認証について

本アプリは、端末の生体認証機能（Face ID / Touch ID）を利用してアクセスを制御します。

  • 生体認証データ（顔・指紋のデータ）は、Apple社のSecure Enclaveに保存されており、本アプリが直接アクセス・取得・保存することはありません。
  • 本アプリは、iOSが提供する認証結果（成功/失敗）のみを受け取ります。

4. 外部サービスとの連携

本アプリは、以下のApple社が提供する標準サービスを利用しています。

  • App Store / StoreKit: アプリ内課金およびサブスクリプションの管理のために利用されます。

これらのサービスによるデータの取り扱いについては、Apple社のプライバシーポリシーをご参照ください。

5. データの削除

アプリを削除すると、デバイスに保存されたすべてのデータ（暗号化された保管データおよびKeychain内の暗号化キー）が削除されます。

6. お問い合わせ

本アプリに関するお問い合わせは、App StoreのサポートページまたはGitHubリポジトリよりご連絡ください。
