# 📋 CHANGELOG (TapKey)

## [1.0] - 2026-02-08（審査提出）

### 新機能
- パスワード自動生成（長さ・文字種カスタマイズ可能）
- ワンタップコピー（ID / パスワード）
- AES-256-GCM暗号化（CryptoKit）によるデータ保護
- Keychain連携による暗号化キー管理
- 生体認証ロック（Face ID / Touch ID）— デフォルトOFF、設定で有効化可能
- クリップボード自動クリア（10〜120秒設定可能）
- サービス名・IDでのインクリメンタルサーチ
- メモ機能
- TapKey Premium（¥980 買い切り）— 保存件数無制限
- 完全オフライン動作

### セキュリティ
- Keychainアクセス制御のACL動的切替（生体認証ON/OFF連動）
- バックグラウンド移行時の即時ロック＆クリップボードクリア
- ITSAppUsesNonExemptEncryption = NO（Apple標準暗号化のみ使用）

### リリース準備
- iPhone専用（iPad非対応）に設定
- プライバシーポリシー・利用規約作成（GitHub Pages公開）
- サポートページ作成（GitHub Pages公開）
- App Store説明文・キーワード・スクリーンショット準備
- 年齢レーティング: 4+（全年齢対象）
