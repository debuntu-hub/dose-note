# 🏦 会社OS 銀行API連携サーバー (MCP)

GMO青空ネット銀行のAPI（Sunabar環境）に接続し、Copilotから直接残高や明細を取得するMCPサーバーです。

## ✅ セットアップ完了

すでに以下が完了しています：
- Python仮想環境の構築
- 必要なパッケージのインストール
- アクセストークンの設定
- API接続テスト成功
- **MCPサーバーの実装完了**

## 🚀 使い方

### 1. VS Code を再起動

MCPサーバーを認識させるため、**VS Code を完全に再起動**してください。

### 2. Copilotに話しかける

再起動後、Copilotに以下のように質問できます：

```
今の口座残高を教えて
```

```
過去30日の入出金明細を見せて
```

```
今月の資金移動サマリーを取得して
```

### 3. 提供されるツール

#### 基本機能

##### `get_account_balance`
- 現在の残高、前日残高、前月残高を取得

##### `get_transactions`
- 指定期間の入出金明細を取得
- パラメータ: `days`（デフォルト30日）

##### `get_monthly_summary`
- 指定月の入出金サマリーを取得（FCF分析用）
- パラメータ: `year`, `month`（省略時は今月）

#### 高度な機能（NEW！）

##### `generate_fcf_data` 🆕
- **FCF入力データの自動生成**
- App Store入金を自動識別し、Apple手数料30%を自動計算
- `data/fcf_input.csv` に追加するCSV行を生成
- パラメータ: `year`, `month`, `app_name`
- 使い方: 「今月のFCFデータを生成して」

##### `analyze_cash_flow` 🆕
- **資金移動の分析・アラート機能**
- 大きな入出金を自動検知
- 1日で大きく残高が変動した日を報告
- パラメータ: `days`, `alert_threshold`（閾値）
- 使い方: 「過去30日の資金移動を分析して」

##### `get_all_accounts` 🆕
- **全口座一覧の取得（複数口座対応）**
- 代表口座の識別
- SPアカウント情報の表示
- 使い方: 「全口座を表示して」

## 🛠 トラブルシューティング

### MCPサーバーが認識されない

1. VS Codeを完全に再起動
2. コマンドパレット（Cmd+Shift+P）→「Developer: Reload Window」
3. `.vscode/settings.json` が正しく配置されているか確認

### トークンエラーが出る

アクセストークンの有効期限が切れた場合：
1. [Sunabarポータル](https://portal.sunabar.gmo-aozora.com/login)にログイン
2. 「sunabarサービスサイトで使える銀行口座」→「更新」ボタン
3. 新しいトークンの取得
4. `.env` ファイルの `ACCESS_TOKEN` を更新

## 🎯 次のステップ

このMCPサーバーを使って：

### 月次FCF管理（自動化）
1. 月末に「今月のFCFデータを生成して」とCopilotに指示
2. 生成されたCSV行を `data/fcf_input.csv` にコピペ
3. 「FCFレポートを更新して」で自動集計
4. **従来の手作業が5分→30秒に短縮！**

### 資金移動監視
1. 「過去7日の資金移動を分析して」で週次チェック
2. 大きな出金があれば自動アラート
3. 予想外の支出を早期発見

### 複数口座管理（本番移行後）
1. 「全口座を表示して」で一覧確認
2. 各口座の残高を一元管理
3. 資金配分の最適化

### 本番API移行の準備
- 現在：Sunabar（テスト環境）
- 移行先：GMO青空ネット銀行 本番API
- 必要な作業：
  1. 本番APIアクセス申請
  2. `.env`の`ACCESS_TOKEN`と`BASE_URL`を更新
  3. 再テスト
