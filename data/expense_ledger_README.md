# 経費台帳 入力ガイド

## ファイル
- `data/expense_ledger.csv`

## カラム定義

| カラム | 説明 | 例 |
|---|---|---|
| date | 日付 (YYYY-MM-DD) | 2026-02-01 |
| category | 勘定科目 | 雑費, 消耗品費, 通信費, 研究開発費 |
| item | 品名・内容 | Apple Developer 年会費 |
| amount | 支払額（税込） | 12980 |
| account_type | 支払手段 | 事業用クレジットカード, 事業口座, 事業主借 |
| deductible_ratio | 経費算入率 (%) | 100, 50, 30 |
| deductible_amount | 経費算入額 | 12980 |
| note | 備考 | 家事按分30%, テスト専用端末 |

## 勘定科目ガイド

| 支出内容 | 勘定科目 | 按分 |
|---|---|---|
| Apple Developer 年会費 | 雑費 or 研究開発費 | 100% |
| テスト専用端末（10万未満） | 消耗品費 | 100% |
| 普段使い端末（10万未満） | 消耗品費 | 30-50%（家事按分） |
| 端末（10万以上） | 固定資産（減価償却） | 按分率に応じ |
| SaaS・ツール費 | 通信費 or 雑費 | 100% |
| 外注費 | 外注費 | 100% |
| 広告費 | 広告宣伝費 | 100% |
| 素材購入（画像等） | 消耗品費 | 100% |

## 家事按分の記録方法

1. `amount` に全額を記入
2. `deductible_ratio` に按分率を記入（例: 30）
3. `deductible_amount` に按分後の金額を記入（例: amount × 30%）
4. `note` に按分根拠を記入（例: "Screen Time事業利用30%"）

## 事業主借の記録

個人資金から事業経費を支払った場合：
- `account_type` を `事業主借` に設定
- 後日精算した場合は `note` に精算日を記入

## 入力タイミング
- 支出発生の都度、または月末にまとめて入力
- 最低月1回は更新すること
