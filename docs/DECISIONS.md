# 📋 最終判断ログ (DECISIONS)

**目的**: CEOによる重要な意思決定を時系列で記録する正式文書

---

## 記録ルール

- 各判断には一意のID（DEC-YYYY-MM-DD-NN）を付与
- 判断日時、判断内容、理由、影響範囲を必ず記載
- このファイルの変更は独立したcommitとする
