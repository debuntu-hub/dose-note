# 🧾 Exit デューデリジェンスチェックリスト

本書は、アプリ売却時に
「買い手が不安に思うポイント」を事前に潰すためのチェックリストである。

---

## 1. ビジネス・財務（FCF）

- [ ] 月次FCFが6ヶ月以上プラス
- [ ] FCFの定義が明確（売上 − Apple手数料 − コスト）
- [ ] アプリ別FCFが算出できる
- [ ] 機能別FCFが説明できる
- [ ] FCFのブレが±20%以内
- [ ] 売上・コストの元データ（CSV）が存在する

---

## 2. 収益モデル

- [ ] Free / Premium の区分が明確
- [ ] 課金導線がSRSに明記されている
- [ ] サブスク or 買い切りの条件が説明できる
- [ ] 将来の価格変更が技術的に可能

---

## 3. 技術・コード

- [ ] ビルドが再現可能
- [ ] 最新OSで動作確認済み
- [ ] 外部依存が最小限
- [ ] 課金（StoreKit等）がモジュール化されている
- [ ] コメント・構造が第三者に理解可能
- [ ] 秘密情報（APIキー等）が含まれていない

---

## 4. ドキュメント整備状況

- [ ] PRD.md が存在する
- [ ] SRS.md が存在する
- [ ] CEO_DASHBOARD.md が最新
- [ ] DECISIONS.md に経営判断が残っている
- [ ] CHANGELOG.md が更新されている

---

## 5. 運用・属人性リスク

- [ ] 運用が自動化されている
- [ ] 日常運用にCEOがほぼ関与していない
- [ ] 障害対応手順が明記されている
- [ ] 「この人しか分からない」作業がない

---

## 6. 法務・リスク

- [ ] 免責事項が明記されている
- [ ] 医療・金融など規制リスクが回避されている
- [ ] 利用規約・プライバシーポリシーが存在する
- [ ] 著作権・外部ライブラリ問題がない

---

## 判定

- [ ] Exit可能（売却に進める）
- [ ] 一部改善後にExit
- [ ] Exit不可（時期尚早）

※ 判定はCEOが行う

👉
このチェックが全部◯なら、
「売れない理由がない」状態です。
