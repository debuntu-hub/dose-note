# 📜 変更履歴 (CHANGELOG)

**目的**: 仕様変更・手戻り・重要な実装変更を時系列で記録

---

## 記録ルール

- 形式: `[YYYY-MM-DD] カテゴリ: 変更内容`
- カテゴリ:
  - `[PRD]` - 企画の変更
  - `[SRS]` - 仕様の変更
  - `[実装]` - 重要な実装変更
  - `[手戻り]` - 手戻りの発生
  - `[システム]` - 会社OS自体の変更
