# プライバシーポリシー

**制定日**: 2026年2月1日

本プライバシーポリシーは、**Dose Note**（以下、「本アプリ」といいます）における利用者情報の取り扱いについて定めたものです。

## 1. 収集する情報

本アプリは、利用者のプライバシーを最大限尊重するため、**個人情報を収集・送信しません。**

- **入力データ**: 服用記録データは、すべて利用者のデバイス内（ローカルストレージ）および利用者のiCloudアカウント（バックアップ等のシステム機能による）にのみ保存されます。
- **解析データ**: 開発者を含む第三者のサーバーへ、服用記録データを自動的に送信することはありません。

## 2. データの利用目的

本アプリに入力されたデータは、以下の目的でのみ利用されます。

- アプリ内での履歴表示、グラフ化、統計情報の提供のため
- iOSのシステム機能（StoreKit等）による定期購読（サブスクリプション）の管理のため

## 3. 外部サービスとの連携

本アプリは、以下のApple社が提供する標準サービスを利用しています。

- **iCloud / CloudKit**: データのバックアップやデバイス間同期のために利用される場合があります。
- **App Store / StoreKit**: アプリ内課金およびサブスクリプションの管理のために利用されます。

これらのサービスによるデータの取り扱いについては、Apple社のプライバシーポリシーをご参照ください。

## 4. お問い合わせ

本アプリに関するお問い合わせは、App StoreのサポートページまたはGitHubリポジトリよりご連絡ください。
