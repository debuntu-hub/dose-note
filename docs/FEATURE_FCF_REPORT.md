## 📝 分析の前提条件

### 売上配賦の考え方
1. **Premium売上を機能別に仮配賦**
2. **配賦基準**: 課金動機への貢献度（初期仮説）
3. **精度より意思決定**: 完璧な配賦は求めない

### 維持コストの考え方
1. **人件費は含めない**（会社OS方針）
2. **外注費**: その機能のみに紐づく外注費を計上
3. **ツール費**: 機能固有のAPI費用など（該当なし）

### Free機能の扱い
- **売上**: 間接的な課金貢献（配賦困難）
- **FCF**: 計算対象外（ただしコストは監視）
- **判断**: ユーザー体験・課金導線の観点で評価
