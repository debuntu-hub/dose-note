## 🚀 移行手順

### Step 1: 本番API接続申請（1〜2週間）

#### 1.1 申請方法（3つの選択肢）

**方法A: インターネットバンキングから申請（推奨）**
1. GMO青空ネット銀行のインターネットバンキングにログイン
   - URL: https://ib.gmo-aozora.com/
2. メニューから「各種サービス」→「API連携」を選択
3. 「API利用申請」ボタンをクリック
4. 利用目的等を入力して送信

**方法B: 電話で問い合わせ**
- **カスタマーセンター**: 0120-0180-39
- **受付時間**: 平日 9:00〜17:00
- **伝えること**: 「自社口座のAPI利用を申請したい」

**方法C: メールで問い合わせ**
- **問い合わせフォーム**: https://gmo-aozora.com/contact/
- **件名**: API利用申請について
- **本文**: 
  ```
  GMO青空ネット銀行の口座を保有しております。
  自社口座の入出金明細を自動取得するため、
  API利用を申請したく、手続き方法を教えてください。
  
  口座番号: [あなたの口座番号]
  目的: 自社のキャッシュフロー管理自動化（参照系のみ）
  ```

#### 1.2 必要書類の準備
- 利用目的書（どのようにAPIを使うか）
- 会社情報（個人事業主の場合は個人情報）
- システム構成図（簡単なものでOK）

#### 1.3 申請内容の記入例

**利用目的**:
```
自社のフリーキャッシュフロー（FCF）管理を自動化するため、
銀行口座の入出金明細を定期的に取得し、会計データと連携させる
システムを構築する。

取得データ：
- 口座残高
- 入出金明細（月次）
- 取引詳細

利用形態：
- プライベートアクセス（自社口座のみ）
- 参照系APIのみ使用（振込等の更新系は使用しない）
```

**システム構成**:
```
VS Code (開発環境)
  ↓
MCPサーバー (Python)
  ↓
GMO青空ネット銀行API (参照系)
  ↓
データ保存 (ローカルCSV)
```

#### 1.4 審査待ち
- 通常1〜2週間で審査結果が通知される
- 追加ヒアリングが入る場合あり

## ⚠️ 注意事項

### セキュリティ
1. **本番トークンは絶対に公開しない**
   - `.env`は`.gitignore`に含まれていることを確認
   - GitHubや公開リポジトリにpushしない
   
2. **トークンの有効期限管理**
   - 本番トークンは定期的に更新が必要
   - 有効期限切れ時の通知設定を検討

3. **アクセスログの確認**
   - 本番ポータルで定期的にAPIアクセスログを確認
   - 不正アクセスの早期発見

### データ管理
1. **Sunabarデータとの混在防止**
   - テストデータと本番データを明確に区別
   - `data/fcf_input.csv`に本番データを入力する際は注意

2. **バックアップ**
   - 本番移行前に現在の設定をバックアップ
   - 問題があればすぐにSunabarに戻せるようにする
