### 【判断】本番API利用方針：個人口座での利用可否
- [ ] 判断待ち（2026年2月7日）
- GMO青空ネット銀行の口座種別：**個人口座**
- API利用可否：**要確認**（個人口座ではAPI利用できない可能性あり）

**状況**:
- 現在：Sunabar（テスト環境）で全機能動作中
- 問題点：本番APIは法人/個人事業主向けの可能性が高い
- 確認方法：カスタマーセンター（0120-0180-39）に電話確認

**選択肢**:

**A. まず電話で確認する（推奨）**
- 明日にでもカスタマーセンターに電話
- 「個人口座でAPI利用できるか」を確認
- 費用：無料、所要時間：5分
- → 利用可能なら本番申請へ
- → 利用不可なら選択肢B〜Dを検討

**B. Sunabarで継続開発（現実的）**
- メリット：
  - 今すぐ使える（設定済み）
  - 全機能が動作する
  - 開発コストゼロ
- デメリット：
  - テスト環境（残高0円）
  - 実際のApp Store入金は手動入力が必要
- 適用：当面の自動化には十分

**C. 個人事業主として開業・口座開設**
- メリット：
  - 確実にAPI利用可能
  - 事業としての信頼性向上
  - 確定申告時の経費計上が明確
- デメリット：
  - 開業届の提出が必要
  - 新規口座開設に時間（1〜2週間）
  - 資金の移動が必要
- 適用：事業として本格化する場合

**D. 他行のAPIサービスを検討**
- 住信SBIネット銀行など
- 費用・対応状況を別途調査が必要

**判断基準**:
- 今すぐ本番API必要？ → No（Sunabarで開発継続可能）
- 将来的に必要？ → Yes（App Store入金の自動識別のため）
- 開業予定は？ → 収益が安定したら検討

**推奨アクション**:
1. **短期（今週）**: 電話で個人口座のAPI利用可否を確認（5分）
2. **中期（1〜3ヶ月）**: Sunabarで継続開発、手動でFCF入力
3. **長期（収益安定後）**: 必要に応じて個人事業主開業・本番API移行
