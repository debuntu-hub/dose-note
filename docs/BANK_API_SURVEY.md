# GMOあおぞらネット銀行 API 調査報告書

**調査日**: 2026年2月6日
**対象**: GMOあおぞらネット銀行 API（参照系・明細取得）

## 1. 概要
自社サービスへの組み込み、および自社業務効率化（自社利用）を目的としたAPI利用の可否と仕様を調査した。
特に「電子決済等代行業者」としての登録なしに利用できる「プライベートアクセス（自社利用）」の可否に重点を置いた。

## 2. 調査結果サマリ

| 項目 | 内容 | 備考 |
|---|---|---|
| **利用要件** | 法人・個人事業主・個人 | 「プライベートアクセス」契約により自社利用可 |
| **コスト** | **無料** | 原則無償（明記あり） |
| **認証方式** | OAuth 2.0 | 認可コードフロー等の標準的な仕組み |
| **開発リソース** | **Python SDKあり** | 公式GitHubにて公開、日本語ドキュメント充実 |
| **取得データ** | 残高、入出金明細、振込状況など | 参照系はほぼ網羅 |

## 3. 詳細調査

### 3.1 API利用要件と契約形態
- **「プライベートアクセス」** という契約形態が存在する。
    - **定義**: 法人口座（個人事業主含む）を保有している顧客が、**自社口座に対して**APIアクセスを行う利用形態。
    - **メリット**: 「電子決済等代行業者」としての登録・契約が**不要**。
    - **対象**: 法人および個人事業主。SDKには `ganb_personal_client`（個人用）も含まれており、広義の個人利用もスコープに含まれている可能性が高いが、ビジネス用途推奨。
    - **審査**: 「接続申し込み」→「ヒアリングシート提出」→「接続審査」→「契約締結」のフローが必要（最短1〜2週間）。

### 3.2 コスト
- API利用料は「原則無償」と公式サイトに明記されている。
- テスト環境（sunabar）も無償で利用可能。

### 3.3 認証方式
- **OAuth 2.0** を採用。
- アクセストークン（JWT形式の可能性大）を利用してAPIリクエストを行う。
- 有効期限切れ時の更新（リフレッシュトークン）の仕組みもSDKに含まれている。

### 3.4 取得できるデータ（参照系）
- **口座情報照会**: 口座一覧、残高照会
- **入出金明細照会**: 指定期間の明細取得
- **振込管理**: 振込依頼、振込状況照会
- **Visaデビット**: 取引明細照会

### 3.5 開発リソース
- **公式SDK**: GitHubにて公開中。
    - Python: [gmo-aozora-api-python](https://github.com/gmoaozora/gmo-aozora-api-python)
    - その他: Ruby, Java, Node.js, Go, PHP
- **ドキュメント**: [API開発者ポータル](https://api.gmo-aozora.com/ganb/developer/api-docs/)（要登録）
- **テスト環境**: 「sunabar（銀行API実験場）」が提供されており、本番契約前に開発・検証が可能。

### 3.6 個人口座向けAPIの技術的仕様（2026/02/06追記）
- **SDKの構成**: 公式Python SDKには `ganb_personal_client` パッケージが含まれており、明確に `ganb_corporate_client` と区別されている。
- **エンドポイント**:
    - 法人: `https://api.gmo-aozora.com/ganb/api/corporation/v1`
    - 個人: `https://api.gmo-aozora.com/ganb/api/personal/v1`
- **示唆**: 技術的には個人口座向けのAPI機能一式が実装・提供されていることが確認できた。

## 4. 個人の開発者（自社利用）への適合性
- **結論**: **非常に高い**。
- **理由**:
    1.  **契約ハードルの低さ**: 代行業者登録不要の「プライベートアクセス」が明示されている。
    2.  **コスト**: 無料であるため、小規模開発や実験的導入に適している。
    3.  **Python SDK**: 公式で用意されており、スクラッチで認証周りを実装する手間が省ける。
    4.  **開発環境**: sunabarで即座に試せるため、契約待ちの間に開発を進められる。

## 5. 次のアクション案

3.  **本番申請**: 自社利用要件が満たせることが確認でき次第、Webから接続申込を行う。
